# Design Instructions

These rules must be followed for all UI components and page designs in this project:

## Colors
- **Primary Color**: `#df0000`
- **Background/Secondary Color**: `white` (`#ffffff`)

## Effects
- **Box Shadows**: No box shadows are allowed anywhere in the design (`box-shadow: none`).

## Border Radius
- **Maximum Border Radius**: Border radius must never exceed `8px`. Use smaller border radius values if needed, but `8px` is the absolute limit.
